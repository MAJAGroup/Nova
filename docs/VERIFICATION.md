# Verification evidence

Automated evidence is generated by `npm test`; screenshots are written to ignored `artifacts/`.

The functional story is registration → authenticated client → owned API → real Chromium → private egress proxy → deterministic website → image and semantic presentation → persisted workspace and history.

Tests exercise this full path and deliberately verify browser-side JavaScript executes in the server page, rather than an iframe/client reconstruction. Native browser input, graph branches, panes, storage recovery and ownership checks are asserted against actual page/API state. Agent tests use a deterministic model fixture against a real page; this fixture is used only by tests.

The UI test runs at 1440×1000 and 390×844, scans workspace and structured views using axe-core, verifies keyboard command focus, star nodes, and reduced-motion behavior, and captures workspace/universe/mobile PNGs. Final results are recorded in PROGRESS.md after execution.

Container runtime and external model integration remain unverified for the reasons in KNOWN_LIMITATIONS.md.

Native desktop evidence: `npm run test:desktop` passed against both the Electron source and packaged executable. The final Linux AppImage was also launched in extraction mode and passed the same fixture-driven native interaction, star inspector, split, close/reopen and recovery test. `npm test` passed 15 tests, and the native desktop scenario passed separately.
