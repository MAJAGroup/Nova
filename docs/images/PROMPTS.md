# Nova README product visuals

Created from screenshots of the running Nova application using an isolated demo profile. The `.example` pages and saved browsing records are sample data. Original captures are in `../screenshots/`; the capture script is `../../scripts/capture-readme.cjs`.

Presentation framing and artwork were made with the built-in image generation tool in edit/compositing mode. No CLI image API was used. Exact generation prompts and input roles follow.

## hero

Inputs: `../screenshots/new-tab.png`

```text
Use case: compositing / ads-marketing. Create a premium desktop software product showcase for Nova's GitHub README, landscape 16:10, high resolution. INPUT IMAGE 1 is the authoritative real Nova new-tab screenshot and the edit target. Preserve its interface, Nova lettering, galaxy, controls, typography, links and layout faithfully; do not invent, replace or improve the UI.
Build an elegant editorial launch composition AROUND the screenshot. Obsidian/navy background #050a14, a subtle cyan and lavender atmospheric glow, sparse fine stars, exceptionally restrained orbital linework, sophisticated negative space. Feature the real screenshot front-facing in one large floating rounded rectangular viewport with a thin glass edge and soft believable shadow. No laptop, phone, monitor hardware or fake window buttons. Make the screenshot occupy most of the lower two thirds; keep its aspect ratio, ensure crisp legible details, and keep the galaxy visible. Outside the viewport, above it, typeset large beautiful clean editorial sans-serif copy, left aligned: "Your browser. A wider universe." Add the small brand word "Nova" and a minimal small caption "A little curiosity. Infinite possibility." Only add those exact words outside the existing screenshot. Polished product design, not a raw screenshot on a flat background. Avoid excessive neon, rockets, stock-photo scenery, clutter, invented features, unreadable text, additional UI, watermarks and exaggerated perspective. The finished image must feel like a coherent professional software launch visual, with a clean 5% safe margin.
```
